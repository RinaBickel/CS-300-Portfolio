# CS-300-Portfolio
Portfolio artifacts for CS 300 Data Structures and Algorithms
### Project Relection ###

_**What was the problem you were solving in the projects for this course?**_

The primary purpose of both these assignments was to design a software program that could assist academic counselors in retrieving course information regarding the Computer Science program. For this purpose, the software program had to retrieve course information from a file, arrange them alphabetically, and also enable the user to locate a certain course along with its prerequisites. In project one, I did an analysis of various data structures in order to find out the most suitable one. In project two, I made use of the binary search tree data structure in C++.

_**How did you approach the problem?**_

I looked over the requirements so that I could figure out waht was needed for the program to work properly. I then worked on the pseudocode for each of the three data structures. The hash table was good for searching, but I would still have to sort the courses separately. The binary search tree made more sense to me because it could display everything in order without that extra step.

_**How did you overcome any roadblocks you encountered while going thorugh the activities or project?**_

A challenge that I was met with was taking the pseudocode I had written and turning it into a working C++ code. When doing this I had to pay close attention to how the information was loaded, stored, and searched. When errors occured, I had to go back through the code, find the cause, and make the corrections. This helped me better understand how the different functions worked together. 

_**How has your work on this project expanded your approach to designing software and developing programs?**_

Before working on these projects, I was more focused on getting a program to work. I have now come to realize that the planning for the management of the information by the program is equally important as actually coding the program itself. By comparing all three data structures, I was able to see clearly how some methods of doing things are more efficient than others in terms of what the program is supposed to achieve.

_**How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?**_

These projects provided an understanding as to why the need for organization and clarity within coding. By splitting up the programming into functions to load, search, and display the courses, I found it much easier to change one function without affecting the rest of the code. Through these projects I was able to see that giving the code and the functions good names and adding comments would allow me to easily interpret the code in the future. In the future, I hope to keep coding in an organized and easily modifiable way.
